# 🛒 Tienda Don Pedro

Aplicación sencilla para organizar los productos y clientes de una tienda de barrio. Permite consultar el inventario y calcular el valor total de los productos.

## Productos

| Producto | Precio |
|---|---:|
| Leche 1L | $4.500 |
| Pan tajado | $6.500 |
| Huevos x12 | $14.000 |
| Café 500g | $18.000 |
| Panela | $3.500 |
| Arroz 1kg | $4.500 |
